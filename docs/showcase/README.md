# Showcase books

These real public-domain books are used in the README's reader examples. The
EPUBs retain their Project Gutenberg notices; the Chinese sample adds vertical
writing styles without replacing its source notices.

- [Alice's Adventures in Wonderland](alice-in-wonderland.epub) — Lewis Carroll,
  Project Gutenberg [#11](https://www.gutenberg.org/ebooks/11).
- [The Raven](the-raven.epub) — Edgar Allan Poe, Project Gutenberg
  [#17192](https://www.gutenberg.org/ebooks/17192).
- [Pride and Prejudice](pride-and-prejudice.pdf) — Jane Austen, a PDF from the
  [GITenberg edition of Project Gutenberg #1342](https://github.com/GITenberg/Pride-and-Prejudice_1342).
- [Dream of the Red Chamber](chinese-vertical-red-chamber.epub) — Cao Xueqin,
  Project Gutenberg [#24264](https://www.gutenberg.org/ebooks/24264); the
  included copy is adapted for vertical reading.

The Gutenberg books are marked public domain in the United States. Check the
source notices and local law before redistribution elsewhere.
