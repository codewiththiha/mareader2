Page AI arrives: summarize, translate or simplify any page, kept with
the book. This release also gathers everything since v0.0.2.

## What's new

- **Page AI.** Right-click a page to summarize it, translate it or
  simplify it. A PDF's result covers its page on the same paper and is
  set smaller to fit. Numbered bubbles switch between results and the
  original page. Code, pictures and tables are never sent and keep
  their places.
- **A book's results become pages.** In an EPUB, Markdown or text book,
  a result is laid into the book in your own type. A long one runs on
  over more pages, font changes set it again, and turning it off gives
  the book its own pages back. Your place, bookmarks and highlights
  hold.
- **Type for a PDF's results.** Once a PDF has an AI page, Settings ›
  Appearance shows the font, size and spacing its results use.
- **Continuous mode.** Translate or simplify as you read: after a short
  stay on a finished page, the next few pages are asked ahead. Moving
  far away pauses and asks before carrying on.
- **Results kept with the book.** Results are saved and come back next
  time. Redo, copy or delete one from its bubble.
- **Organize with AI.** Let a model sort loose books onto shelves. A run
  can be paused, resumed after an error, or discarded.
- **Library from the sidebar.** Move, rename and nest shelves, make new
  ones and import books, all from the sidebar's tree.
- **Named models.** Give each model a name and pick which one each task
  uses. Busy models say so instead of failing quietly.
- **Lighter.** Rendered pages are handed over without a copy, and
  machine fallback fonts are mapped once, so long books use less memory.

## Fixes

- Erasing a book's data now removes its AI pages and Explain answers
  from the disk as well.
- Page AI results never scroll inside themselves; the wheel always
  scrolls the book.
- A lifted pane's space closes up when it's moved.

## Which file to download

| System | File | Install |
| --- | --- | --- |
| macOS 11 or later, Apple silicon | `Mareader_0.0.3_aarch64.dmg` | open it and drag Mareader to Applications |
| macOS 11 or later, Intel | `Mareader_0.0.3_x64.dmg` | the same |
| Windows 10 or 11 | `mareader_0.0.3_x64-setup.exe` | run it; it installs for you alone, no administrator needed |
| Windows, managed machines | `mareader_0.0.3_x64_en-US.msi` | `msiexec /i` it, or deploy it as usual |
| Debian, Ubuntu, Mint, Pop!_OS | `mareader_0.0.3_amd64.deb` | `sudo apt install ./mareader_0.0.3_amd64.deb` |
| Arch and its family | `mareader_0.0.3_x86_64.tar.gz` and `PKGBUILD` | put both in one folder, then `makepkg -si` |
| Any other Linux (glibc 2.35 or newer) | `mareader_0.0.3_x86_64.AppImage` | `chmod +x` it, then run it |

Installing over v0.0.2 keeps your library, settings and highlights.
`SHA256SUMS` lists every file's checksum: `sha256sum -c SHA256SUMS
--ignore-missing` on Linux, `shasum -a 256 -c SHA256SUMS --ignore-missing`
on a Mac.

## The first launch

This build is not signed by Apple or Microsoft yet, so each system asks
once:

- **macOS:** "Apple could not verify Mareader". Choose Done, then open
  System Settings › Privacy & Security and choose Open Anyway next to
  Mareader. Later launches open directly.
- **Windows:** "Windows protected your PC". Choose More info, then Run
  anyway.
- **Linux:** nothing to approve. The AppImage only needs to be executable.

## Known limits

- Page AI needs a model: set one up in Settings › AI. Apple Intelligence
  needs a Mac with Apple silicon and macOS 26, and doesn't speak every
  language.
- A PDF's results are text only.
- Your library stays on this computer; syncing between machines comes in
  a later release.
- Linux packages are for x86_64 only; ARM Linux and Windows on ARM have
  no build yet.

Before publishing, CI built every installer on its own system, then
installed each one, opened a book with it and removed it again.
