Mareader has its own icon: an open book whose edges draw an M, with one
line highlighted. This release also gathers everything since v0.0.1.

## What's new

- **Dictionary page.** A Dictionary button in the Library and reader title
  bars, or Cmd/Ctrl+Shift+D, opens a full dictionary: every pack or one,
  Languages mode from one language to another (bridged through English
  when no pack joins them), close matches, recent searches and the
  keyboard throughout.
- **Floating dictionary.** In the reader it floats over the page instead:
  move it, resize it, fold it to a small pill that shows the word and its
  answer, or open it as a page. While it's open, Look up answers in it and
  the selection stays. Settings › Dictionary › In the reader can choose
  the full page instead.
- **Notes and bookmarks.** Write a note on any highlight; a Notes panel
  lists them by chapter, with search. Bookmark pages. Export highlights
  and notes, and restyle one highlight or several at once.
- **A rebuilt Library.** A home-screen grid you arrange by dragging, with
  shelves you make by stacking books, multi-select, a list view, watched
  folders with a single import form, links and duplicates, and a compact
  way to remove books.
- **Reading.** Grab empty space to pan the pages; hold a pane to lift and
  move it; open pictures large with a double click; footnotes open in
  place; reopen recent books from an empty pane.
- **Look and feel.** A compact, foldable Appearance popover; a keyboard
  shortcut sheet; a redesigned lookup card that points at its word;
  Burmese and other complex scripts shaped in every panel; small text
  kept readable on every paper.
- **AI.** Models refresh and fetch on their own; one download fetches the
  word-level data, with options after.

## Which file to download

| System | File | Install |
| --- | --- | --- |
| macOS 11 or later, Apple silicon | `Mareader_0.0.2_aarch64.dmg` | open it and drag Mareader to Applications |
| macOS 11 or later, Intel | `Mareader_0.0.2_x64.dmg` | the same |
| Windows 10 or 11 | `mareader_0.0.2_x64-setup.exe` | run it; it installs for you alone, no administrator needed |
| Windows, managed machines | `mareader_0.0.2_x64_en-US.msi` | `msiexec /i` it, or deploy it as usual |
| Debian, Ubuntu, Mint, Pop!_OS | `mareader_0.0.2_amd64.deb` | `sudo apt install ./mareader_0.0.2_amd64.deb` |
| Arch and its family | `mareader_0.0.2_x86_64.tar.gz` and `PKGBUILD` | put both in one folder, then `makepkg -si` |
| Any other Linux (glibc 2.35 or newer) | `mareader_0.0.2_x86_64.AppImage` | `chmod +x` it, then run it |

Installing over v0.0.1 keeps your library, settings and highlights.
`SHA256SUMS` lists every file's checksum: `sha256sum -c SHA256SUMS
--ignore-missing` on Linux, `shasum -a 256 -c SHA256SUMS --ignore-missing`
on a Mac.

## The first launch

This build is not signed by Apple or Microsoft yet, so each system asks
once:

- **macOS:** "Apple could not verify Mareader". Choose Done, then open
  System Settings › Privacy & Security and choose Open Anyway next to
  Mareader. Later launches open directly.
- **Windows:** "Windows protected your PC". Choose More info, then Run
  anyway.
- **Linux:** nothing to approve. The AppImage only needs to be executable.

macOS and Windows may keep showing the old icon for a while, as they
cache icons; it updates after a restart or once the cache refreshes.

## Known limits

- Apple Intelligence needs a Mac with Apple silicon and macOS 26.
- Your library stays on this computer; syncing between machines comes in
  a later release.
- Linux packages are for x86_64 only; ARM Linux and Windows on ARM have
  no build yet.

Before publishing, CI built every installer on its own system, then
installed each one, opened a book with it and removed it again.
