The first build of Mareader for macOS, Windows and Linux: a calm reader
for PDF, EPUB, plain text and Markdown, native (egui and wgpu, no webview).

Inside: single, spread, vertical and horizontal page views; every
typography setting for books; up to four panes, each with its own theme;
light, dark and dim papers with tints, textures and grain; a library with
shelves and watched folders; highlights, gloss cards, offline dictionaries,
CEFR word levels and Explain through Apple Intelligence or the AI provider
you choose; search in both formats; and full keyboard control.

## Which file to download

| System | File | Install |
| --- | --- | --- |
| macOS 11 or later, Apple silicon | `Mareader_0.0.1_aarch64.dmg` | open it and drag Mareader to Applications |
| macOS 11 or later, Intel | `Mareader_0.0.1_x64.dmg` | the same |
| Windows 10 or 11 | `mareader_0.0.1_x64-setup.exe` | run it; it installs for you alone, no administrator needed |
| Windows, managed machines | `mareader_0.0.1_x64_en-US.msi` | `msiexec /i` it, or deploy it as usual |
| Debian, Ubuntu, Mint, Pop!_OS | `mareader_0.0.1_amd64.deb` | `sudo apt install ./mareader_0.0.1_amd64.deb` |
| Arch and its family | `mareader_0.0.1_x86_64.tar.gz` and `PKGBUILD` | put both in one folder, then `makepkg -si` |
| Any other Linux (glibc 2.35 or newer) | `mareader_0.0.1_x86_64.AppImage` | `chmod +x` it, then run it |

Each installer opens PDF, EPUB, text (`.txt`, `.text`) and Markdown
(`.md`, `.markdown`, `.mdown`) files from your file manager. `SHA256SUMS`
lists every file's checksum: `sha256sum -c SHA256SUMS --ignore-missing`
on Linux, `shasum -a 256 -c SHA256SUMS --ignore-missing` on a Mac.

## The first launch

This build is not signed by Apple or Microsoft yet, so each system asks
once:

- **macOS:** "Apple could not verify Mareader". Choose Done, then open
  System Settings › Privacy & Security and choose Open Anyway next to
  Mareader. Later launches open directly.
- **Windows:** "Windows protected your PC". Choose More info, then Run
  anyway.
- **Linux:** nothing to approve. The AppImage only needs to be executable.

## Known limits

- On Windows, the setup makes Mareader open PDF, EPUB, text and Markdown
  files unless you already chose another app for them; `.txt` files
  then open in Mareader rather than Notepad. Uninstalling restores them.
- Apple Intelligence needs a Mac with Apple silicon and macOS 26.
- Your library stays on this computer; syncing between machines comes in
  a later release.
- Linux packages are for x86_64 only; ARM Linux and Windows on ARM have
  no build yet.

Before publishing, CI built every installer on its own system, then
installed each one, opened a book with it and removed it again. The Arch
package is the exception: CI checks its contents and `PKGBUILD`, as no
Arch runner exists.
